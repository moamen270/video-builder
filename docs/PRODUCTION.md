# Production checklist — Dummy Sticky

One pass per video, in this order. Items marked **auto** are enforced or
generated by the engine; everything else is a human/agent check. Do not skip
the manual ones because the automated ones passed.

## 0. Concept (before writing)

- [ ] One character, one obsession, one payoff. Same Dummy Sticky style as the
      last 10 videos — no format changes until the metrics sheet says so.
- [ ] Target 25–40 s. Hard cap 60 s (**auto**: compile warns > 45 s).

## Standard shape (every character short)

`bare` opening: character alone in a `spotlight`, the title as `hook_card`, one famous line in
his voice, no progress bar/watermark → the story → the character hits the **screen** with his
signature move and it shatters (`screen_crack`, stays broken) → `cta` scene in the **narrator**
voice (`af_heart`): "Follow Dummy Sticky for more." + `follow_card`. Reference: `jhin-four-shots` v6.

## 1. Hook — first 1–3 seconds

- [ ] Frame 0 already shows the interesting thing: claws out, gun raised,
      Batman mid-fall, the melon already on screen. No intro, no logo, no walk-on.
- [ ] A 3–8 word **text hook** on screen from frame 0 that works with the
      sound off (`social.hook` doubles as the on-screen hook card).
- [ ] First spoken line is a threat or a payoff, never an introduction
      ("Everyone thinks I'm just…" ✗ — "They know what they did." ✓).
- [ ] The opening frame is the cover on every platform: check it as a still.
- [ ] Write 2–3 alternative hooks in `notes`; render the best, keep the others
      for the next version if the 3-second retention is weak.
- **auto**: compile warns if the first scene is > 2.5 s with no visual event
  (strike/shot/throw/prop/entrance/SFX) inside its first second.

## 2. Retention

- [ ] No dead time: `pauseAfter` ≤ 0.4 except one dramatic beat; silent
      scenes ≤ 2 s and something must move in them.
- [ ] A visible change every ≤ 2 s (pose change, prop, strike, camera, bubble).
- [ ] Important words are on screen (captions are auto; put numbers and names
      in `emphasis`).
- [ ] Each scene sets up the next: a count ("One… Two…"), a threat, a question.
- [ ] Every action lands on its word (check `alignment.json` timings vs anchors).

## 3. Payoff

- [ ] The last 3–5 s deliver the thing the hook promised (the laugh, the
      fourth shot, the batarang in the screen). Payoff before CTA, never after.

## 4. CTA — exactly one

- [ ] One ask in the last ~2 s, from the list: *Follow Dummy Sticky for more* ·
      *Comment who he should go after next* · *Part 2 is coming — follow so you
      don't miss it*. Never stack two.
- [ ] Handle visible (**auto**: watermark on every frame from `brand.json`).
- [ ] The same ask goes in `social.pinnedComment` as a question.

## 5. Quality control (watch the full MP4 once, sound on, once muted)

| check | how |
|---|---|
| animation mistakes | contact sheet + scrub `output/v<N>/final.mp4`; limbs through props, hands not reaching targets, wrong facing |
| inconsistent objects | props/bodies keep position across cuts (re-declare extras with same `x` + `fallDir`) |
| text / grammar | captions are the script — proofread `speech`; check emphasis words exist |
| audio glitches | clicks at scene joins, FX clipping (growl/villain), laugh clip level vs voice |
| chatterbox scenes | every `[laugh]`/`[chuckle]` actually performed (not read or skipped); same speaker across all scenes with the same `voiceRef`; no swallowed first word (the line starts on the cut) |
| pronunciation | listen to every name (Jhin, Riddler); respell phonetically in `speech` if wrong |
| narration ↔ visual timing | each anchored event within ~0.1 s of its word |
| continuity | same theme, character colour, prop scale between scenes |
| awkward cuts | transitions only where the subject changes |
| missing / frozen frames | **auto**: QA duration check + per-second luminance |
| loudness | **auto**: −14 LUFS master; **manual**: dialogue audible under SFX |
| copyright | only procedural SFX/music in `assets/`; parody characters drawn as stickmen, no logos, no game/film audio |
| facts | anything stated as true is true |

## 6. Platform versions

One 1080×1920 master (`output/v<N>/final.mp4`) uploaded to YouTube Shorts,
Instagram Reels, Facebook Reels, TikTok. Before each upload:

- [ ] Opening frame reads as a cover.
- [ ] Captions and watermark inside the safe area (**auto**: layouts respect
      `VIDEO.safeArea` — top 250 / bottom 420 / left 60 / right 140).
- [ ] Platform caption from `output/v<N>/social.md` (**auto**; `vb social <slug>`
      regenerates after editing `manifest.social`).
- [ ] Same title/hook everywhere; hashtags per platform as generated
      (`#shorts` on YouTube, `#fyp` on TikTok).
- [ ] Pin the comment question within the first hour. Do not edit title or
      description in the first 24 h.

## 7. Packaging (all in the manifest, generated with the render)

`social`: `title` · `hook` · `description` · `tags` · `hashtags` ·
`pinnedComment` · `coverText`. Compile warns when it's missing (**auto**).

## 8. Track performance

`analytics/videos.csv` — one row per video per platform, filled at 24 h, 72 h
and 7 d. Columns: date, slug, version, platform, views, retention_3s,
avg_watch_s, completion, likes, comments, shares, saves, followers_gained,
hook_text, notes. **First-3-second retention is the primary metric** until it
is consistently above ~70 %; then optimise completion.

## 9. Cadence

Two videos a week, fixed days, ~19:00 Cairo (12:00 US Eastern). Keep the
concept constant for 10–20 videos; change one variable at a time (hook style,
length, character) and read the sheet before changing another.
